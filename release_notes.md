## Perfect Dark Launcher for macOS

A native SwiftUI launcher application for the Perfect Dark PC port with bundled game executables.

### Features
- **Bundled Executables**: Game executables included - no separate download needed!
- **ROM Selection**: Drag & drop or browse for your ROM file (.z64 format)
- **Automatic Region Detection**: Detects NTSC, PAL, and JPN ROMs and uses correct executable
- **Video Settings**: MacBook-optimized resolution presets (16:10 and Retina), fullscreen, VSync, MSAA, texture filtering
- **MacBook Optimization**:
  - 16:10 aspect ratio presets (1440x900, 1680x1050, 2560x1600)
  - Retina/HiDPI resolution support
  - ProMotion display support (120Hz option)
  - Trackpad mode for better trackpad sensitivity
- **Game Settings**: Skip intro, HUD positioning, screen shake, explosions
- **Player Settings**: FOV, mouse sensitivity, aim modes
- **Audio Settings**: Sound enable/disable

### Requirements
- macOS 12.0 (Monterey) or later
- Apple Silicon Mac (arm64)
- Perfect Dark ROM file (.z64 format)

### Installation
1. Download the DMG file below
2. Open the DMG and drag Perfect Dark Launcher to Applications
3. Launch the app and select your ROM file
4. Configure settings as desired
5. Click Launch Game
